# Product Data Analytics Learning

제품 데이터 분석을 지표 정의에서 실무 액션까지 차례로 학습하는 canonical 공간입니다. 현재는 이론과 설계를 Markdown으로 정리하며, 분석 코드와 가상환경은 실습을 시작할 때 추가합니다.

## 학습 순서

1. `00_Event_Log_Design/`: 이벤트 로그 설계
2. `01_Metrics/`: 제품 지표와 지표 체계
3. `02_Funnel_Analysis/`: 퍼널 분석
4. `03_Cohort_Analysis/`: 코호트와 리텐션 분석
5. `04_RFM_Analysis/`: RFM 고객 세분화

공통 개념은 `notes/`, 실습용 데이터의 원천·보관 규칙은 `data/README.md`에 기록합니다. 향후 `05_AB_Test`, `06_Experiment_Analysis`, `07_Product_Metrics`로 확장할 수 있습니다.

## 공통 분석 프레임

> 문제 정의 → 지표 정의 → 분해 → 비교 → 세분화 → 가설 → 검증 → 액션 → 재측정
